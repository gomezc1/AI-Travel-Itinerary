# Getting Started
#### 1) Clone the repository
```bash
git clone https://github.com/gomezc1/AI-Travel-Itinerary.git
```
#### 2) Open Terminal 
- Navigate to the clone repository
```bash
cd C:\Desktop\AI-Travel-Itinerary 
```
#### 3) Run the Python server 
```bash
python -m http.server 5000
```
### 4) Open browser 
- Navigate to localhost
```bash
http://localhost:5000/
```
